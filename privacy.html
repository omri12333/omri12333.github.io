Privacy Policy - openclaw

Last updated: October 3, 2026

openclaw is a private, single-user personal assistant. Its only user is its owner.

What data it accesses

With the owner's consent, it accesses the owner's Google Calendar (read and create events) and Gmail (read messages and create drafts).

How data is used

Data is used only to answer the owner's own requests. It is processed on the owner's computer and by the AI model service the owner uses to run the assistant. It is not sold, shared with third parties, or used for advertising.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and deletion

Access tokens are stored locally on the owner's computer. Access can be revoked at any time at myaccount.google.com/permissions.
